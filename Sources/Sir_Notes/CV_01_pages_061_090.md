## PDF page 70

Histogram Equalisation
• Histogram Equalization is an image enhancement technique used to improve the contrast of an image by redistributing the intensity values so that the histogram becomes approximately uniform.
• It is particularly useful when the image is too dark or too bright.

## PDF page 71

Histogram Equalisation
Spreading out the frequencies in an image (or equalising the image) is a simple way to improve dark or washed out images.

The formula for histogram equalisation: sk = T(rk) = sum p_r(r_j) = sum n_j/n.
• rk: input intensity
• sk: processed intensity
• k: intensity range
• nj: frequency of intensity j
• n: sum of all frequencies

Output intensity (s): 0 1 2 3 4 5 6 7
Number of pixels: 0 3 0 4 0 0 6 3

Important: Histogram equalization does not necessarily produce a perfectly flat histogram, especially for a small/discrete image. Its purpose is to redistribute intensities to improve use of the available dynamic range and consequently improve contrast.

## PDF page 84

Image Filtering in Spatial Domain
1. Flip the kernel in both horizontal and vertical directions (center of kernel must be provided).
2. Move over the array with kernel centered at interested point.
3. Multiply kernel data with overlapped area.
4. Sum or accumulate the output.

Note: Size of output must be same size as input and image must be padded for undefined pixels.

Image Restoration
• Purpose: restore a degraded/distorted image to its original content and quality.
• Distinction from image enhancement: restoration assumes a degradation model that is known or can be estimated.
• Original content and quality ≠ good looking.

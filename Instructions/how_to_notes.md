# How to Write Theory Notes

Use `Sources/Sir_Notes/CV_01.pdf` as the content authority and `sourcemap.md` + filtered PYQ analysis as the routing layer.

Write for the expected midsem, not for textbook completeness.

For each `CORE` topic:

- preserve Sir's terminology and framing;
- include the exact concepts, distinctions, formulas and diagrams that matter for exam answers;
- shape depth around the kinds of questions seen in the relevant PYQs;
- avoid generic expansion beyond what improves answerability.

For `SUPPLEMENTARY` topics:

- keep them clearly separated;
- include only the minimum material needed to answer the likely exam-style question;
- state why the topic was retained.

Do not include `EXCLUDE` topics.

Use the helper Sir-note Markdown files only for navigation/search. If a detail is visual, formula-heavy, ambiguous or missing there, verify it in the original PDF.

The result in `Notes/notes.md` should be compact but sufficient to write a complete exam answer without reopening the source for ordinary theory questions.

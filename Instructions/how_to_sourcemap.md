# How to Build the Sourcemap

Build `sourcemap.md` from **Sir's original PDF** at `Sources/Sir_Notes/CV_01.pdf`.

The helper `CV_01_pages_*.md` files may be used to find terms quickly, but page ranges, formulas, diagrams, numerical procedures and scope decisions must be checked against the PDF when needed.

For each meaningful topic record:

- topic name;
- Sir-PDF page range;
- `THEORY`, `NUMERICAL`, or `BOTH`;
- important formulas/procedures/visuals to revisit;
- linked relevant PYQ question IDs;
- class-guidance signal if any;
- `CORE` or `SUPPLEMENTARY` status.

Keep the sourcemap compact. It is an index/routing layer, not another set of notes.

Do not add official-syllabus topics merely to make the map complete. Add an outside-Sir topic only when it survives the supplementary relevance filter defined in `AGENTS.md`.

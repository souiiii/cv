# How to Analyze PYQs

Use the `.md` PYQ files as the primary analysis source. Open the matching PDF only when wording, marks, a matrix, a diagram or transcription needs verification.

Analyze **every potentially relevant question from all supplied papers**, including legacy papers. Do not discard a useful question only because its paper is lower priority.

For each question:

1. identify the tested topic/pattern;
2. compare it with `Sources/Sir_Notes/CV_01.pdf`;
3. classify it as `CORE`, `SUPPLEMENTARY`, or `EXCLUDE`;
4. preserve marks/question structure where available;
5. give one short justification.

Definitions:

- `CORE`: directly supported by Sir's notes and should shape preparation.
- `SUPPLEMENTARY`: outside/weak in Sir's notes but close enough and sufficiently supported by PYQ/class/official-reference evidence to justify minimal exam-safety coverage.
- `EXCLUDE`: old-syllabus, peripheral or unlikely for the present paper.

Do not use raw frequency alone. Sir's notes define scope; PYQs define likely question forms within and just around that scope.

Write results to:

- `PYQ_Analysis/question_mapping.md`
- `PYQ_Analysis/topic_frequency.md`
- `PYQ_Analysis/gaps.md`

Avoid repeating full question text unnecessarily. Reuse question IDs/references after the first mapping.
